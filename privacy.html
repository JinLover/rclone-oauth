Privacy Policy

Last updated: September 22, 2026

This application is operated by JinLover for personal use only.

Google Drive access and use

rclone accesses the owner's Google Drive files and metadata as permitted by the granted OAuth scopes and the commands the owner runs. This access is used only to manage, copy, or synchronize the owner's files.

Storage and sharing

OAuth tokens are stored in the owner's rclone configuration. File contents and metadata may be stored on devices or storage destinations selected by the owner. This informational website does not receive Google OAuth tokens or Google Drive data.

The application does not sell Google user data or use it for advertising. Transfers occur only to destinations selected by the owner.

Revoking access and deleting data

The owner can revoke the application's access through Google Account connections and remove the saved rclone configuration. Previously transferred files must be deleted separately from their destinations.

This website

This static site uses no analytics scripts or forms. GitHub Pages hosts it and may process request information under GitHub's Privacy Statement.
